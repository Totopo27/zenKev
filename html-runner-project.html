Zen Voice Navigator: Especificación Técnica

Objetivo: Navegación por voz nativa, local, determinista y accesible para personas ciegas sobre Zen Browser (Gecko).

Premisa Central: Sustituir la navegación visual tradicional por el Árbol de Accesibilidad (AOM) de Gecko, combinando un Sistema 1 determinista (ModernBERT en CPU sub-40ms) y un Sistema 2 multimodal de contingencia para botones mudos.

1. Comparativa de Componentes y Ecosistema

Componente Opción Adoptada Motivo de Selección
Detección de Voz (VAD) Silero VAD (ONNX C++) <5 MB en RAM, latencia <20 ms, corte inmediato de audio (barge-in).
Transcripción (STT) Whisper.cpp (tiny.en / base) Streaming optimizado para CPU vía instrucciones AVX2 / NEON.
Sistema 1 (Decisión) ModernBERT NLI (ONNX Runtime) Inferencia de paso único (single forward pass) en 15–35 ms; coste $0.
Sistema 2 (Contingencia) SmolVLM / Moondream2 (4-bit) Inspección de recortes (128x128 px) de iconos sin texto ARIA.
Motor Web Base Zen Browser (Gecko AOM) Acceso directo a nsIAccessibilityService sin parsear HTML visual.

4. Extractor Nativo de Accesibilidad en Zen (.mjs)

export class ZenAOMCollector {
  constructor() {
    this.accService = Cc["@mozilla.org/accessibilityService;1"]
                        .getService(Ci.nsIAccessibilityService);
  }

  getInteractiveCandidates(contentDoc) {
    const rootAcc = this.accService.getAccessibleFor(contentDoc);
    const candidates = [];

    this._traverse(rootAcc, (accNode) => {
      const role = accNode.role;
      if (this._isActionableRole(role)) {
        candidates.push({
          id: accNode.uniqueID,
          role: this.accService.getStringRole(role),
          name: accNode.name?.trim() || "",
          description: accNode.description?.trim() || ""
        });
      }
    });

    return candidates;
  }

  _isActionableRole(role) {
    const actionable = [
      Ci.nsIAccessibleRole.ROLE_PUSHBUTTON,
      Ci.nsIAccessibleRole.ROLE_LINK,
      Ci.nsIAccessibleRole.ROLE_ENTRY,
      Ci.nsIAccessibleRole.ROLE_CHECKBUTTON
    ];
    return actionable.includes(role);
  }

  _traverse(node, callback) {
    if (!node) return;
    callback(node);
    let child = node.firstChild;
    while (child) {
      this._traverse(child, callback);
      child = child.nextSibling;
    }
  }
}

5. Reglas de Interacción para Usuarios Ciegos

  • Barge-In Inmediato: En cuanto Silero VAD detecta sonido del usuario, silencia la salida de audio del sintetizador en ≤ 20 ms.
  • Gramática Concisa: Respuestas breves de estado ("Página cargada, 4 campos") sin frases de cortesía innecesarias.
  • Independencia Visual: Las acciones se ejecutan por foco de accesibilidad nativo, no simulando clics de ratón sobre coordenadas arbitrarias.
